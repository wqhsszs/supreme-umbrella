# 明白办 — 面向长辈的 AI 社区通知行动助手

把一条看不懂的社区通知，变成一张能照着做的行动卡：说清是什么、谁能参加、什么时候、要带什么、下一步做什么，并且**每个事实都能点开看原文依据**。

## 它凭什么可信

模型输出的不是自由文本，而是固定结构的 JSON；程序逐条校验，**每条「原文依据」必须能在通知原文中逐字找到**。校验不通过则自动重试 1 次，仍不通过就显示「没看明白」，不渲染行动卡——宁可不给，也不给错的。
