# 12｜工具、素材来源与原创记录（C 轮）

> 本文件记录 C 轮实际使用的工具、生成物与人工判断，A/B 轮记录见各自 delivery/12。
> 原则：不夸大 AI 贡献，不抹掉 AI 参与；没有的写"未使用"，不编造。

## 一、执行主体与工具链

| 环节 | 工具 / 环境 | 实际说明 |
|---|---|---|
| 统筹与代码执行 | AI 助手 WorkBuddy（开发执行模型 **MiniMax-M3.1-Flash**，用户指定） | C 轮代码（ocr.js / speech.js / 界面）与材料由其执行 |
| 截图取字（产品运行时） | **minimax-m3.1-flash 原生多模态**，WorkBuddy 云服务免密钥通道 | 消息格式为 OpenAI 兼容 `image_url` + base64 data URL；**先实测可用再接入**（见 evidence/capability-probe）；识图模型由模型目录 `supportsImages === true` 过滤，不猜 |
| 事实整理（产品运行时） | 同通道第二次独立调用，`prompts/system-prompt.txt` | 与取字共用模型、但两次请求、两套提示词，职责分开 |
| 产品内朗读（产品运行时） | **浏览器 Web Speech API**（本机音色 Microsoft Huihui） | **不是云端 TTS**；声音取决于设备；不能导出音频文件，界面不提供下载按钮 |
| 视频旁白（材料制作） | Windows SAPI5（`Microsoft Huihui`） | 与产品内朗读是两个通道，材料里分开标注 |
| 朗读原声录制（未完成） | WASAPI 环回录音（pyaudiowpatch）+ 有界面 Edge，脚本已备 | 环回设备实测可用（−27 dB），但需要真实卡片才能播放；通道限流后未执行，故本轮无音频证据 |
| OCR 测试图 | Python Pillow 逐字排版生成（tools/gen_ocr_samples.py） | 10 张全部为自编虚构通知；**不用图像模型生成测试图**，避免错字当标准答案 |
| 界面截图 / 录屏 | Microsoft Edge + playwright-core（CDP `Page.startScreencast`） | 上传/核对/结果/朗读各状态；录屏为真实操作 |
| 视频合成 | Pillow 逐帧排版 + ffmpeg（libx264 / AAC / yuv420p） | 1080×1920、15fps |
| 信息图 | HTML/CSS 可编辑源 → Edge 截图 | 公众版五步图、技术实现图（C 轮重画，分开取字/整理/校验/人工核对/朗读） |
| PDF / DOCX | Edge 打印引擎 + python-docx | 说明书 10 页 PDF 与同源 DOCX |
| 依赖 | playwright-core、Pillow、imageio-ffmpeg、pyaudiowpatch、pywin32 | 仅制作与测试期使用，不进产品运行时 |

**没有使用的**：云 TTS 服务、第三方 OCR 服务、第三方音乐、图库素材、真人照片、名人肖像、品牌或政府标识。

## 二、能力核实记录（先验证、后接入）

| 事项 | 怎么核实的 | 结论 |
|---|---|---|
| 模型目录是否有识图模型 | 调 `llm_list_models`（2026-10-23） | `minimax-m3.1-flash` 等 20+ 模型 `supportsImages: true`；GLM/混元/Kimi 系列亦有 |
| SDK 图像消息格式 | 抓取 SDK 源码：`messages` 原样透传到 `/chat/completions` | 格式由后端决定 → 用 `image_url`+base64 实测 |
| 实际识图效果 | 用自编通知图真实调用（evidence 内留有返回原文） | 可用，取字准确；据此接入 |
| 云端 TTS | 模型目录无 TTS 模型；SDK 源码无 `audio/speech` 接口 | **不可用** → 产品内朗读走浏览器 Web Speech，如实标注 |
| 环回录音 | ffmpeg 列设备只有麦克风 → 装 pyaudiowpatch 取 WASAPI loopback | 可用，实测录到 −27 dB 的真实朗读声 |

## 四、两个"声音"的区分（重要）

1. **产品内朗读**：用户在网页里点"读给家人听"时发出的声音，来自用户自己的设备（Web Speech API）。视频朗读段用 WASAPI 环回从系统扬声器录下（`assets/audio/speech-live.wav`，18.53 秒），不是另找 TTS 合成。
2. **视频旁白**：制作材料时用 Windows SAPI5 合成的解说音。两者都不是真人配音，也都没有克隆任何人的声音；工具与通道分别列在上表，不混写。

## 五、运行时模型变更（2026-10-24）

原选用的 `deepseek-v4.1-flash` 对该应用持续返回 **HTTP 403**（`llm.models.list()` 正常、`chat/completions` 403），同一应用下 `minimax-m3.1-flash`、`kimi-k2.6`、`glm-5.3-flash`、`hy3`、`auto` 均正常。
最终运行时改用 **minimax-m3.1-flash**（原生多模态，`supportsImages: true`，取字约 5.5 秒、整理约 6–12 秒，识图与 JSON 均实测通过），并在 `js/config.js` 的 `preferredModelHints` / `ocr.modelHints` 中把 kimi-k2.6、glm-5.3-flash 列为后备。
`assets/evidence/capability-probe.json` 记录的识图格式核实仍以 deepseek 为对象，属历史事实，不改写。
