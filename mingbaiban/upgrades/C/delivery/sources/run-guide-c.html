附件 08

在线体验与运行说明

预览地址：https://mingbaiban-42482.app.workbuddy.host/
无需注册、无需登录。手机与电脑都能用。

一、怎么试（5 分钟，含截图与朗读）

  1. 文字方式：点首页「示例一 · 手机使用指导」→「整理成行动卡」，等 3—15 秒（真实模型在处理）。
  2. 截图方式：切到「上传通知截图」→ 选一张通知截图（可用本包 assets/ocr-samples/ 里的自编样例）→「识别文字」。
  3. 核对：左边原图、右边文字逐行看；改好后勾选「我已核对」，再点「已核对文字，整理行动卡」。不勾选就无法整理。
  4. 看结论卡下面的「谁适用」「何时、何地」——报名截止与活动开始是两个时间，地点分别是一楼服务台、二楼活动室。
  5. 点任意一项下面的「对照核对后的通知文字」看原句；截图来源还能点「查看这张通知的原图」。
  6. 点「读给家人听」，用设备自带中文语音整卡朗读；可暂停、继续、停止。
  7. 点「复制行动卡，发给家人」，可粘贴到聊天里。

二、版本怎么核对

控制台执行 window.MBB_CONFIG.appVersion，应返回 1.3.0-c7。来源说明（截图来源会写"文字由 模型名 取出后经整理者核对"）与实际模型名都显示在页面上。

三、真实模型调用的条件

项目说明
通道WorkBuddy 云服务免密钥通道；浏览器直连数据面，服务端按 Origin 校验
运行时模型deepseek-v4.1-flash（原生多模态）；取字与整理是两次独立调用、两套提示词
取字参数图片先在前端缩到长边 1600px、JPEG 质量 0.86；单次超时 60 秒，网络类错误自动重试 1 次
整理参数流式输出、temperature 0.1、单次 45 秒、失败最多重试 1 次
域名限制换域名或本地 file:// 打开时，模型调用会被服务端拒绝，页面显示「AI 服务还没连接上」——这是设计行为
配额由平台侧决定；被限流时页面显示「请求被限流，请稍后重试」，不给假答案

四、截图识别的边界（如实）

  • 支持 JPG/PNG/WebP、单张 ≤8MB、长边自动缩到 1600px；HEIC 明确提示不支持并建议导出 JPG。
  • 取字只提取可见文字：不改写、不补年份/楼层/电话；看不清处标注「［此处看不清，请对照图片］」；不输出置信度。
  • 无文字、太模糊、文件损坏：都停在原图页并给出下一步，保留用户输入。
  • 核对是整理者的操作，不是社区认证；改字后旧卡片、复制文本、朗读全部作废，需重新整理。
  • 图片只在当前页面内存中，不写浏览器存储；不发送到除模型通道外的地址。截图里如带姓名电话，建议先裁掉。

五、朗读的边界（如实）

  • 声音来自这台设备（浏览器 Web Speech API + 系统中文音色），不是云端配音，音色随设备变化。
  • 朗读内容由已校验的卡片数据确定性拼出：数字等价改写（9:00→9点）但数值不变；"通知未说明""前后不一致""还要确认"照读；勾选读成"整理者已勾选 N 项"，并说明不代表已报名。
  • 没有中文音色或浏览器不支持时会明确提示，不显示假成功。
  • 不能导出音频文件，所以产品里没有"下载语音"按钮；把卡读给长辈听必须当场播放，或用复制文本让对方设备朗读。

六、隐私边界

  • 文字与截图只用于本次请求；不建账号、不建历史库、不写日志，刷新即清空。
  • 模型服务由平台托管，平台侧数据处理不在本产品控制内，不承诺"绝不保留"。
  • 页面除模型通道与 CDN 上的 SDK 外无外部请求。

七、本地运行（仅看界面）

cd C/project && python3 -m http.server 8124 → 打开 http://127.0.0.1:8124/。 本地 Origin 不在通道白名单内，模型调用会被拒（页面有明确提示）；要试真实功能请用线上地址。
