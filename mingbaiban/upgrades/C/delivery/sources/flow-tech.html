取字与整理是两次独立调用、两套提示词；中间必须经过人工核对。校验不过就不出卡，朗读只读已校验的数据。

  • 图片先校验：JPG/PNG/WebP、≤8MB
  • 长边缩到 1600px
  • 只在页面内存，不写 localStorage

STEP 6 · 呈现 / 朗读

卡片、复制、设备朗读

朗读文本由已校验数据确定性拼接。

  • 复制文本与勾选状态一致
  • Web Speech API（设备中文音色）
  • 9:00 → 9点，数值不变
  • 未说明/冲突/待确认必须读出
浏览器

失败与降级（都保留可恢复路径）

取字超时 / 无识图模型 / 图里没字 / 文件损坏：停在原图页，提示换图或改用粘贴；不显示假结果。朗读失败或无中文音色：提示原因，可改用复制。

数据边界（如实说明）

图片与文字只在当前页面会话内使用，不建账号、不建历史库、不写浏览器存储；请求会经过平台托管的模型通道，平台侧如何处理不在本产品控制内，因此不承诺“绝不留存”。

真实职责划分

识图与整理用的是同一个多模态模型，但是两次独立请求、两套提示词；OCR 不是另一个厂家的服务，朗读也不是云端 TTS。材料里按实际情况标注。

运行形态：静态页面 + WorkBuddy 云服务免密钥模型通道（浏览器直连，无自建代理）；前端只放 publishableKey（公开标识），不含任何长期密钥。
