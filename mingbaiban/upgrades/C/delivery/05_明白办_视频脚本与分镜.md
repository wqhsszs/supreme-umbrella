## 二、与 C 轮任务书的对应

| 要求 | 本片情况 |
|---|---|
| 30—180 秒、含独立 AI 旁白 | 满足（153 秒；SAPI 旁白 11 段） |
| 展示"截图 → 核对识别文字 → 行动卡 → 朗读" | P2—P6 连续展示；P8/P9 补边界 |
| 产品朗读片段与旁白错开 | 满足：旁白 S7 在 15.8 秒后结束，随后才是朗读原声 |
| 主要画面为真实操作 | 除结尾插画，全部为真实录屏 |
| 不机械加长旧片 | 全新录制，未复用 B 轮画面 |

## 三、修改建议

1. 想缩短：优先删 P8/P9（各约 10 秒）。
2. 想换旁白：替换 `assets/audio/S*.wav` 后重跑 `tools/make_video_c.py`，画面与字幕自动重算。
3. 想完整读完整张卡：需要约 2 分钟素材，建议单独出一条"听卡"视频。
