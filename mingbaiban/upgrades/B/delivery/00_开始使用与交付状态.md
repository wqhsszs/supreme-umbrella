## 四、必须知道的限制

1. **预览就是原地址**：平台把同一工作区的发布指向同一应用，B 轮覆盖了 A 轮（进而覆盖了 v1.0.0）的线上版本。原版代码在 `mingbaiban/app/` 与 git `9ad17e8`、A 轮在 `upgrades/A/`，都可回滚。
2. **旁白不是云端大模型 TTS**：用的是 Windows 系统语音合成（Huihui），听感偏朗读腔；未克隆真人声音。
3. **没有真人试用、没有真机测试**：材料里没有任何效果数字，只有技术测试数据。
4. **只能处理文字**：截图识别、卡片朗读都还只是计划（C 轮）。
5. **模型输出有波动**：同一输入多次调用措辞会变，视频里展示的是其中一次真实结果。
