一、怎么试（3 分钟）

  1. 打开地址，点首页「示例一 · 手机使用指导」。
  2. 点「整理成行动卡」，等 3—15 秒（真实模型在处理）。
  3. 看结论卡下面的「谁适用」「何时、何地」——注意报名截止与活动开始是两个时间，地点分别是一楼服务台、二楼活动室。

  5. 点「复制行动卡，发给家人」，可粘贴到聊天里。

二、版本怎么核对

控制台执行 window.MBB_CONFIG.appVersion，应返回 1.2.0-b2。页面页脚也会显示本次实际使用的模型名与耗时。

附件 08（续）

本地运行与部署

一、本地看界面

cd upgrades/B/project
python3 -m http.server 8123 --bind 127.0.0.1
打开 http://127.0.0.1:8123/

本地只能看布局与交互，点「整理成行动卡」会因 Origin 不匹配而失败——这不是 bug。

二、部署要点（踩过的坑）

  • 必须复用同一应用：新建应用会换域名，模型通道 Origin 不匹配，所有调用被拒。
  • 静态资源带版本号：index.html 里的 ?v=1.2.0-b2 是 CDN 缓存键；改前端必须同步改，否则会出现「HTML 新、JS 旧」的混合状态。
  • 发布后等传播：同一域名在不同节点短时可能返回不同版本，连续刷新 5 次核对方可。
  • 测试脚本要等就绪：tools_tests/*.cjs 会等待并核对 appVersion 再开始。
