# 旁白稿（B 轮视频）

> 语言：平实普通话，像说明一件生活小事。不播新闻腔、不煽情、不幼儿化。
> 合成工具：Windows 系统语音合成 SAPI5，音色 `Microsoft Huihui Desktop - Chinese (Simplified)`，Rate=-1，Volume=100。
> 说明：这是**本地系统合成音色**，不是云端大模型 TTS；未克隆或模仿任何真人声音。

| 段 | 时长目标 | 文稿 |
|---|---|---|
| S1 | 8s | 社区发来一条通知：二十五号下午五点前报名，二十六号上午九点活动，一个在一楼，一个在二楼。 |
| S2 | 8s | 家里人先看一遍，把它整理成一张卡，再交给长辈。去不去、怎么办，还是长辈自己定。 |
| S3 | 14s | 打开明白办，把通知原文贴进去，点"整理成行动卡"。这一步是真的在调模型，不是提前写好的答案。 |
| S4 | 17s | 几秒钟后，卡片出来了。先说要办什么，再说谁适用，然后把报名截止和活动开始分开写。 |
| S5 | 15s | 每一项后面都能点开"对照通知原文"，看到通知里的原句。报名在一楼服务台，活动在二楼活动室，地点也分开标着。 |
| S6 | 16s | 通知没写的地方，它会直接写"通知未说明"，不会替社区补。信息前后不一致时，最上面会提醒先问清楚。 |
| S7 | 13s | 要带的东西可以打勾，但打勾只是记下准备到哪一步，不等于已经报名。 |
| S8 | 10s | 点"复制行动卡"，整张卡可以粘贴到聊天里发给家人，缺失和提醒都一起带走。 |
| S9 | 13s | 明白办现在只处理文字，也还没有做过真机测试和长辈试用。它做的是一件事：把通知整理清楚，让人自己决定。 |

合计约 114 秒（以实际合成时长为准，见 `sources/audio-timing.json`）。

## 合成注意事项

1. 引号用中文引号，SAPI 会正常停顿；数字用汉字写（二十五、二十六），避免读成"二五"。
2. 每段单独合成，便于对齐画面；段间不留静音，靠 0.35 秒淡入淡出衔接。
3. 试听检查：首段、S5（数字与楼层密集）、S9（结尾）。
4. 若某段发音错误，只重合成该段，不重做整条。
