# 00_A 轮交付说明

> 本轮：A 轮（网页界面、文案、协助使用流程）。版本 **v1.1.0-a3**。日期 2026-10-23。
> B / C 轮未执行，按任务书由用户后续拖入对应任务书再启动。

## 一、这一轮改了什么（一句话版）

把「长辈自己看通知」的单人工具，改成「**家人或志愿者先整理、再交给长辈**」的协作工具：首页换成整理者视角的文案，结果页按「要办什么 → 谁适用 → 何时何地 → 准备什么 → 下一步 → 还要确认」重排，冲突提醒提到顶部，报名地点与活动地点分开显示，复制内容与勾选状态一致，并补上一处「标了原文要求却拿不出原文」的校验漏洞。

## 二、产品定位变化

| | A 轮之前（v1.0.0） | A 轮之后（v1.1.0-a3） |
|---|---|---|
| 主要操作人 | 长辈本人 | 家人 / 社区志愿者 |
| 受益者 | 长辈 | 长辈（不变） |
| 首页首句 | 收到通知之后，下一步更明白 | 帮家人整理一条社区通知 |
| 主按钮 | 帮我看懂 | 整理成行动卡 |
| 结果页首卡 | 这条通知说的是 | 这条通知要办什么 |
| 复制按钮 | 复制整张行动卡 | 复制行动卡，发给家人 |

说明：没有把长辈写成"看不懂""必须依赖别人"；行动卡正文仍是中性、可独立阅读的语气，长辈拿到卡片能自己看懂。

## 三、实际改动清单

### 1. 首页（A2）
- 首屏改为「帮家人整理一条社区通知」+ 一句说明 + 三步引导（贴通知 → 核对重点 → 复制给家人）。
- 主插画放在主按钮**之后**（手机端）：360×780 视口下主按钮顶部从 823px 提到 **694px**，首屏可见。
- 输入说明写明「暂时只能处理文字。通知是图片的，可以先复制成文字」，**没有放假上传按钮**。
- 三条示例入口文案改为「先用一条示例看看」，样例仍标注「虚构演示样例」。

### 2. 结果页（A3）
- 信息顺序重排为：要办什么 → 谁适用 → 何时、何地 → 家人需要准备什么 → 下一步 → 还要确认什么 → 注意。
- 新增 **`times[].place`**（用途对应地点）：报名截止挂「一楼服务台」，活动开始挂「二楼活动室」，不再合并成一个笼统地点。
- 新增**顶部确认横幅**：有冲突时用双线红框 + `!`，只有含糊时用点线棕框 + `?`；横幅在结论卡之后、其它卡片之前，默认展开。
- 缺失项不再显示「通知未说明 + 通知未说明」两遍，只保留徽章。
- 同一件事只出一个「对照通知原文」按钮（此前地点与时间各出一个，出现「对照通知原文对照通知原文」叠字）。
- 页面文案改为整理者语气：`家人需要准备什么`、`可以先帮家人问清楚`。

### 3. 准备与复制（A4）
- 复制文本按当前勾选状态输出 `[x]` / `[ ]`（此前一律 `[ ]`，与界面不一致）。
- 复制文本固定包含：要办什么 → 先确认的事 → 谁适用 → 各用途时间**与对应地点** → 准备事项 → 下一步（含 required / suggested 区分）→ 待确认问题 → 注意。
- 复制文本末尾写明：「方框打勾记录的是整理者准备到哪一步，不是报名凭证，也不代表已经报名或办好。」
- 复制文本不含模型名、耗时、接口名；这些只在页脚「本次生成信息」。
- 复制成功提示改为「已复制，可粘贴到聊天中发给家人。」；剪贴板失败仍有手动全选复制框。

### 4. 文案与信任（A5）
- 加载：`正在整理时间、地点和准备事项……`（不写固定秒数、不造假进度）。
- 失败：`这次没有整理成功。原文还在，可以再试一次。`
- 缺信息：徽章 + 「原文没有这一项，这里没有替它补上。」
- 冲突：`通知里有前后不一致的地方，先问清楚再安排`
- 关于页：明确区分「我们不建历史数据库」与「平台侧可能的数据处理」，不承诺「绝不上传/绝不保留」；写明未开展真人试用、未做真机测试。

### 5. 校验修正（A7）
- `validate.js` 中 `actions` 的 `required` 分支：**没有引文 / 引文全对不上原文 → 判为校验失败**（此前只记警告，仍会显示并复制成「通知明确要求」）。
- 同步修 `not_notice` 分支：模型返回 `summary: null` 时不再被误判为「整理失败」，能正常显示「这段文字看起来不是社区通知」。
- 网络瞬断增加一次自动重试（此前只在 gateway/model 类错误时重试）。

### 6. 视觉
- 暖米白 `#F7F3EB` + 深墨绿 `#254C40` + 暖橙（装饰 `#B95B36` / 文字 `#8F4322`）。
- 1 张 AI 主插画（家人与长辈在餐桌旁）+ 1 张小幅静物（手机、便签、铅笔、眼镜，用于加载态）。
- 插画下方标注「插画为虚构人物，由 AI 生成，不对应任何真实个人」。
