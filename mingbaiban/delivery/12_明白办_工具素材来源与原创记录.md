# 12｜工具、素材来源与原创记录

> 目的：说明哪些内容由 AI 生成、哪些由人工判断、哪些素材来自何处，便于赛事核查与后续复现。
> 记录原则：不夸大 AI 贡献，也不抹掉 AI 参与；时间与命令均如实记录。

## 一、执行主体与工具链

| 环节 | 工具 / 环境 | 说明 |
|---|---|---|
| 需求梳理与文档撰写 | AI 编程助手 WorkBuddy（开发执行模型 **DeepSeek V4.1 Flash**，由用户在模型选择器中指定） | 需求基线、要求映射、说明书、测试报告、发布文案等文本由 AI 起草，项目组审阅 |
| 代码实现 | 同上 | HTML / CSS / JS / Python / Node 脚本由 AI 编写，人工确认取舍 |
| 产品运行时模型 | **DeepSeek-V4.1-Flash**（`deepseek-v4.1-flash`），经 WorkBuddy 云服务免密钥大模型通道调用 | 由模型列表接口实时读取后选用，页面底部显示本次实际使用的模型 |
| 模型通道 | WorkBuddy 云服务（托管，浏览器直连数据面，Origin 校验） | 未使用自建代理，未在前端保存长期密钥 |
| 浏览器自动化 / 截图 / 测试 | Microsoft Edge + playwright-core（无头） | 访问线上真实版本，执行 12 条用例、10 项行为测试、14 张界面截图 |
| PDF 生成 | Microsoft Edge 打印引擎（通过 playwright `page.pdf`） | 说明书 10 页；运行说明 3 页；测试报告 4 页 |
| DOCX 生成 | python-docx | 与 PDF 同源内容的可编辑稿 |
| 图像生成 | Pillow（程序绘制） | 技术流程图、视频封面、视频各帧、二维码（qrcode 库） |
| 视频编码 | ffmpeg 7.1（imageio-ffmpeg 提供） | H.264 / yuv420p / 30fps / 1080×1920 |
| 包管理 | Node 22.22.2、Python 3.13.12（均为本机受管运行时） | 依赖安装在受管目录内，不污染系统环境 |

**没有使用的**：没有调用任何图像/视频生成大模型（如文生图、文生视频），没有使用第三方素材库，没有使用任何需要付费授权的资源。

## 四、原创性与边界说明

1. **产品逻辑为原创设计**：把通知拆成"事实项 + 状态 + 原文依据"的结构，并由程序回溯校验引文的真实性，是本项目自己确定的实现方案。**不主张技术首创**，也未使用任何他人的同类产品代码。
2. **不声称自研基础模型**：产品使用第三方大语言模型，本项目的工作在提示词设计、输出结构约束、程序侧校验与适老化交互层。
3. **不声称已有成效**：未开展目标用户（长辈）真人试用，一切"提升理解率""减少误读"之类的结论均未验证，文档与视频中均不出现。
4. **开发过程可复现**：所有生成脚本在 `tools/` 下，测试原始记录在 `tests/evidence/` 下，模型提示词在 `app/prompts/` 下。
