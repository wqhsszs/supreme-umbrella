# 访谈提纲（5 分钟版）

> 用法：试用**前**问 A 组问题，试用**后**问 B 组问题。不要跳过 A 组——没有基线就无法判断产品有没有用。

## 准备

- 一部能上网的手机（用长辈自己的手机更好）
- 两条难度相近的通知（一条直接读，一条用产品看）
- 录音（需征得同意）或纸笔记录
- 记录表 `02_试用记录表_空白.csv`

## A 组 · 试用前（约 2 分钟）

1. 您平时收到社区通知，一般是怎么看的？（自己看 / 子女念 / 不看）
2. 最近一条社区通知，您记得是什么事吗？后来您去办了吗？
3. 看通知时，哪一部分最容易搞不清？（时间 / 地点 / 要带什么 / 谁能去）
4. 有没有哪次因为看错通知，白跑一趟或者错过了？
5. （出示第一条通知）这条您看一遍，然后告诉我：什么时候、在哪、要带什么。

> 记录：回答正确数（时间 / 地点 / 材料三项各算一项）、用时、是否需要人帮忙。

## B 组 · 试用后（约 3 分钟）

1. （出示第二条通知，让其用产品看）这张卡片上，哪一行您最先看？
2. 「看原文依据」这个按钮，您知道是做什么的吗？（不解释，先听答案）
3. 卡片上写「通知未说明」，您明白是什么意思吗？
4. 如果要带的东西打了勾，是不是就等于已经报好名了？（**关键理解点**）
5. 这张卡片您会转发给谁吗？会怎么转发？
6. 有哪个字或哪句话您看着别扭、不像人话？
7. 如果明天社区又发一条通知，您还会用它看吗？为什么？

## 记录要点

| 字段 | 说明 |
|---|---|
| 回答正确数 | 0—3，对照 A 组第 5 题的三个要素 |
| 用时 | 从拿到通知到说出答案 |
| 求助次数 | 主动求助 + 卡住超 60 秒给的提示，各记 1 次 |
| 原话 | 直接抄，不改写；用引号 |
| 是否长辈 | 是 / 否（子女代测单独标记，不与长辈数据混算） |

## 提问禁忌

- 不要问"是不是很好用""是不是比原来清楚"——这是引导性提问，答案没有信息量。
- 不要在产品上指指点点。长辈找不到按钮，本身就是最重要的发现。
- 不要在长辈说"看不懂"时急着解释。先问"哪里看不懂"。
