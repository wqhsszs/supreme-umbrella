一、用起来是什么样（普通用户）

  1. 把社区通知的文字复制下来。只支持文字，不支持图片。
  2. 粘贴到输入框，点「帮我看懂」，等 5—20 秒。
  3. 页面给出行动卡：这条通知说的是、谁能参加、时间（按用途分开）、地点、要带什么、您接下来做什么、还要问清楚什么。
  4. 每项后面有「看原文依据」，点开可看到通知里的原句，自己核对。
  5. 准备事项可以打勾；点「复制整张行动卡」可以发给家人。

首页有三条明确标注「虚构演示样例」的通知，可直接点开体验，不会涉及任何真实个人或社区信息。

五、本地运行

本项目是纯静态站点，没有构建步骤。任选一种方式在项目根目录起一个静态服务器即可：

cd app
python3 -m http.server 8000 --bind 0.0.0.0
然后浏览器打开 http://localhost:8000/

注意：模型通道按来源（Origin）校验。直接用 file:// 打开或用与已登记域名不一致的地址访问时，模型调用会被服务端拒绝，页面会显示「AI 服务还没连接上」而不是给假答案。正式使用请走已发布的域名。

六、部署方式

当前版本以静态站点形式托管，发布域名为 mingbaiban-42482.app.workbuddy.host，与云服务环境登记的来源一致。重新发布时必须复用同一个应用，否则域名变化会导致模型调用被拒。
